# Honeypots with Intrusion Behaviour Analysis with ML

This project implements honeypot scripts designed to detect, log, and analyze intrusion attempts, leveraging Artificial Intelligence (AI) and Machine Learning (ML) techniques. By simulating vulnerable services, we capture malicious activity and study the behavior of attackers in a controlled environment to build robust predictive models.

## Features

- **Low Interaction Honeypots**: Simulates common and critical services to attract malicious actors.
- **Intrusion Logging**: Automatically captures and structures connection attempts, network payloads, port scans, and attacker IP intelligence.
- **AI/ML Behaviour Analysis**: Feeds captured honeypot data into machine learning algorithms to identify novel attack patterns, detect zero-day techniques, and cluster threat actor signatures autonomously.
- **Predictive Threat Intelligence**: Uses historical and real-time intrusion data to predict potential attacks and dynamic behavior changes.
